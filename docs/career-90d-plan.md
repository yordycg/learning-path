# Plan 90 días — Primera vía de ingreso + Portfolio

> **Fecha de inicio:** Sáb 2026-09-05 · **Cierre:** principios de Dic 2026 (coincide con fin de F1 / Dic 13).
> **Origen:** decisión de carrera (2026-09-04) tras investigación de mercado (Perplexity + Gemini) sobre el mercado tech chileno de entrada. Este plan es la "vía de ingreso" **en paralelo** al roadmap de C — no lo reemplaza.

---

## Contexto / diagnóstico

- **Situación:** chileno, 8ª región (Biobío/Concepción), estudiante de Ing. en Informática a ~1.5 años de titularse, 31 años, sin urgencia financiera crítica.
- **Driver real:** ansiedad por falta de progreso **tangible** → los 2 marcadores de progreso son: **1) dinero mes a mes**, **2) portfolio mejorado**.
- **Restricción clave:** disponibilidad dispersa (Sáb, Dom, Lun, Mié). El empleo junior formal full-time y el remoto internacional junior son de baja probabilidad con este horario (Gemini estructural; Perplexity más optimista).
- **Lectura del mercado (ambas fuentes):**
  - Frontend/React junior → saturado.
  - Backend formal (Java/Python/.NET) y data → mejor tasa de respuesta, filtro técnico mayor.
  - **C directo casi no se contrata en Chile** → su valor es rigor transferible (Go/Python/Rust), no empleo directo. mysh = diferenciador de portfolio.
  - **Robótica/embebidos en Chile = chico y lento** → archivado como vía de ingreso (solo especialización de largo plazo si hubiera pasión).
  - Vías fiables para estudiante con horario disperso: **ayudantía/I+D universitaria** (pago fijo, flexible) + **freelance por entregable / honorarios**.
- **Expectativa honesta:** el primer peldaño realista es ~CLP 300–550K/mes (ayudantía/honorarios), NO el junior full-time (CLP 900K+). El objetivo del primer ingreso es **abrir el circuito** (plata + línea de CV + prueba tangible), no el sueldo.

---

## Objetivos (los 2 marcadores)

1. **Ingreso:** abrir el circuito — primera plata real entrando (ayudantía **o** primer entregable cobrado).
2. **Portfolio:** mysh como pieza estrella + 2 proyectos mejorados + 1 proyecto nuevo de Python-datos.

**Presupuesto semanal de la vía de ingreso (~7–9 h/sem):**
- Dom 3–4 h → skill Python + portfolio.
- Lun 2 h → búsqueda / postulaciones a ayudantía.
- Mié 2 h → skill Python.
- Sáb → mysh/roadmap (solo ~20 min de admin si sobra).

---

## Fase 0 — Cimientos (Sáb 5 – Mar 8 · días 1–3)

**Definición de hecho:** mysh v1.0 en GitHub público + CV/portfolio actualizados.

- **Sáb 5:** ensamblar **mysh v1.0** (milestone S3) → README claro → commit + `git tag v1.0` → subir a GitHub como pieza pública.
- **Dom 6:** refrescar **CV de 1 página** y LinkedIn con el stack + mysh. Dejar el portfolio con los 2 proyectos presentables (qué hace, captura, link, stack).
- **Mar 8:** listar 3–4 profesores / laboratorios / centros de la facultad de informática para acercarse por ayudantía.

---

## Fase 1 — Ingreso fiable: ayudantía/I+D (Sem 2–5 · Sep)

**Definición de hecho:** ≥1 ayudantía/proyecto universitario conseguido o en conversación avanzada (pago fijo + horario flexible).

- Pedir el **catálogo de ayudantías** a dirección de docencia / departamento de informática.
- Acercarse a **2–3 profesores con proyectos** (fondos tipo ANID/Fondef) con CV de 1 página.
- **Sondear centros/laboratorios** de la facultad (datos, HPC, ML, herramientas) que toquen C/Linux.
- **Postulación oportunista** (no apuesta principal): 1–2/día a "alumno en práctica"/junior remoto desde Biobío (ChileTrabajos, GetOnBoard, LinkedIn filtro remoto). Verificar postulaciones tipo Clikma-UBB.

---

## Fase 2 — Skill de entregable vendible: Python datos (Sem 3–8 · Sep–Oct)

**Definición de hecho:** funcional en scraping + ETL simple en Python (primer entregable freelance vendible). Método code-first.

- **Sem 3–4:** fundamentos Python (tipos, archivos, JSON/CSV).
- **Sem 5–6:** scraping con `requests` + `BeautifulSoup` sobre un caso real (precios, avisos, datos públicos regionales).
- **Sem 7–8:** limpiar y entregar a **CSV/SQL** = mini-ETL. Publicar = 3er proyecto de portfolio.

---

## Fase 3 — Abrir el circuito (Sem 8–13 · Oct–Dic)

**Definición de hecho:** primera plata cobrada (honorarios) o ayudantía activa cobrando.

- **Sem 8–9:** primer entregable freelance (scrape para pyme local/agencia, o Workana/GetOnBoard servicios). Pago por hito; objetivo es **cobrar una vez**.
- **Sem 10–13:** si ayudantía activa → dejar que corra; si freelance → 1–2 entregables más. Decidir en Dic si convertir en postulación junior remoto.
- **Inglés:** 20 min/día hacia **B2** en background (para el salto post-experiencia).
